# Emanuel Ben-David — Academic Website

Source files for [ehb2126.github.io](https://ehb2126.github.io), the academic website of Emanuel Ben-David.

The site is a lightweight, responsive static website built with semantic HTML, CSS, and a small amount of JavaScript. It is served through GitHub Pages.

## Files

- `index.html` — homepage content and metadata
- `styles.css` — layout, typography, and responsive styling
- `script.js` — mobile navigation and small interface enhancements
- `404.html` — custom not-found page
- `robots.txt` and `sitemap.xml` — search-engine discovery
